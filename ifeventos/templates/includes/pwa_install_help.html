{% comment %} Instruções de instalação, por sistema. O botão "Instalar app" abre o painel correspondente quando o navegador NÃO oferece o prompt automático (beforeinstallprompt): - iOS: o Safari nunca emite o evento; precisa do passo a passo no menu. - Android: o Chrome emite o evento quando o site está em HTTPS (contexto seguro). Sem HTTPS (ou em webview de app), sobra o menu do navegador. {% endcomment %} {# ---------- iPhone / iPad ---------- #}

Instalar no iPhone/iPad

  1. Toque em Compartilhar na barra do Safari.
  2. Escolha Adicionar à Tela de Início.
  3. Confirme em Adicionar.
{# ---------- Android ---------- #}

Instalar no Android

  1. Abra este site no Chrome.
  2. Toque no menu ⋮ (três pontos) no canto superior.
  3. Escolha Instalar aplicativo (ou Adicionar à tela inicial).

A instalação exige o site em HTTPS. Abra pela versão publicada (endereço com https://), não pelo IP da máquina de desenvolvimento.
